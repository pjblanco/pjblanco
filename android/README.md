# Android app

A dependency-free WebView shell that ships the site inside the APK, so it
works with **no internet connection and no deployment**. Point it at a live URL
instead with `./gradlew assembleDebug -PsiteUrl=https://your-deployment.example`.

## Build an APK locally

Prerequisites: JDK 17 and the Android SDK (or just open it in Android Studio,
which installs the SDK for you).

```sh
# from the repo root: build the site, bundle it into assets, then assemble
npm run apk
```

The installable APK ends up at
`android/app/build/outputs/apk/debug/app-debug.apk`.

No SDK on this machine? Push the branch — `.github/workflows/android.yml`
builds the APK on GitHub-hosted runners and attaches it as the
`pjblanco-debug-apk` artifact, and this repo also ships the site as an
installable PWA (manifest + service worker).

## Notes

- `minSdk 26` (Android 8.0) keeps the launcher icon as an adaptive vector, no
  raster mipmap buckets needed.
- The release build type is intentionally unsigned; publishing needs a real
  upload keystore that must never be committed.
- The bundled copy of the site is generated by
  [`scripts/bundle-app-assets.mjs`](../scripts/bundle-app-assets.mjs), which
  rewrites root-absolute URLs to `file:///android_asset/www/...` so every page,
  stylesheet, font and image resolves offline. It is gitignored on purpose.
